## 1. DEPLOYMENT ARCHITECTURE OVERVIEW

The application comprises three core components:
1. **Frontend Web Application:** React SPA built with Vite and TypeScript, served via Nginx or static CDN.
2. **Backend API Service:** FastAPI application served by Uvicorn ASGI workers behind a reverse proxy.
3. **Database Cluster:** Managed PostgreSQL 16+ with the `pgvector` extension for semantic search.

## 2. DEPLOYMENT OPTION A: RENDER BLUEPRINT (RECOMMENDED)

The repository includes a ready-to-deploy [`render.yaml`](file:///c:/Users/india/Desktop/amit%20hospitality/render.yaml) specification:

### Steps to Deploy on Render:
1. Connect your Git repository to **Render** (`https://dashboard.render.com`).
2. Navigate to **Blueprints** $\rightarrow$ **New Blueprint Instance**.
3. Select this repository and branch. Render will detect [`render.yaml`](file:///c:/Users/india/Desktop/amit%20hospitality/render.yaml) and automatically configure:
   - **Database:** `amit-concierge-postgres` (PostgreSQL with pgvector enabled).
   - **Backend Web Service:** `amit-concierge-api` running on Python 3.12 with persistent volume disk (`/var/data/uploads`).
   - **Frontend Static Site:** `amit-concierge-ui` running static React build.
4. When prompted, provide your secret credentials:
   - `GEMINI_API_KEY`: Your official Google Gemini API key.
   - `JWT_SECRET_KEY`: Automatically generated by Render if not provided.
   - `INITIAL_ADMIN_PASSWORD`: Automatically generated.
5. Click **Apply**.
6. Render will build both services, run `python -m alembic upgrade head` during the backend build phase, and deploy the application.

## 3. DEPLOYMENT OPTION B: DOCKER COMPOSE (CLOUD VM / VPS)

For AWS EC2, DigitalOcean, or on-premises servers:

### Steps:
1. **Clone Repository & Configure Environment:**
   ```bash
   git clone <repo-url>
   cd amit-hospitality
   cp .env.example .env
   ```
2. **Edit `.env`:** Set `APP_ENV=production`, configure a strong `JWT_SECRET_KEY` (`openssl rand -hex 32`), and set `INITIAL_ADMIN_PASSWORD`.
3. **Build and Run Containers:**
   ```bash
   docker-compose up -d --build
   ```
4. **Run Alembic Migrations inside container:**
   ```bash
   docker-compose exec backend python -m alembic upgrade head
   ```
5. **Verify Running Containers:**
   ```bash
   docker-compose ps
   ```
   Three containers will be running:
   - `amit_concierge_db` (`pgvector/pgvector:pg16` on port 5432)
   - `amit_concierge_api` (FastAPI backend on port 8000)
   - `amit_concierge_ui` (Nginx + React frontend on port 80)

## 4. DEPLOYMENT OPTION C: MANUAL LINUX SERVER DEPLOYMENT

### Step 1: Install PostgreSQL & pgvector
```bash
sudo apt-get update
sudo apt-get install -y postgresql-16 postgresql-16-pgvector libpq-dev
sudo -u postgres psql -c "CREATE USER amit_admin WITH PASSWORD 'YourStrongPassword';"
sudo -u postgres psql -c "CREATE DATABASE amit_concierge OWNER amit_admin;"
sudo -u postgres psql -d amit_concierge -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### Step 2: Configure Systemd Service for Backend
Create `/etc/systemd/system/amit-concierge.service`:
```ini
[Unit]
Description=Amit AI Concierge FastAPI Backend
After=network.target postgresql.service

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/amit-hospitality/backend
EnvironmentFile=/var/www/amit-hospitality/.env
ExecStart=/var/www/amit-hospitality/backend/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
```
Enable and start the service:
```bash
sudo systemctl daemon-reload
sudo systemctl enable amit-concierge
sudo systemctl start amit-concierge
```

### Step 3: Build & Deploy Frontend
```bash
cd /var/www/amit-hospitality/frontend
npm ci
npm run build
sudo cp -r dist/* /var/www/html/
```

### Step 4: Configure Nginx & SSL
Install Certbot for automated Let's Encrypt SSL/TLS certificates:
```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d concierge.amithospitality.com
```

## 5. POST-DEPLOYMENT VERIFICATION

Run the health check endpoint:
```bash
curl -I https://concierge.amithospitality.com/api/v1/health
```
Verify:
1. `HTTP/1.1 200 OK`
2. Security headers are present:
   - `X-Content-Type-Options: nosniff`
   - `X-XSS-Protection: 1; mode=block`
   - `Referrer-Policy: strict-origin-when-cross-origin`
   - `Content-Security-Policy: frame-ancestors ...`
3. Integrations status:
   ```bash
   curl -H "Authorization: Bearer <ADMIN_TOKEN>" https://concierge.amithospitality.com/api/v1/integrations/status
   ```
